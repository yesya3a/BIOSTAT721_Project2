
# BIOSTAT 721 Project 2

## Project Description

This project explores daily air pollution concentrations measured at RDU Airport from 2018 through April 2020. The analysis focuses on CO, PM2.5, and O3, including data cleaning, summary tables, and visualizations of monthly patterns.

## Data Source

The data come from the EPA air quality monitoring station at RDU Airport in North Carolina.

- AQ_2018.csv: 2018 measurements
- AQ_2019.csv: 2019 measurements
- AQ_2020.csv: January–April 2020 measurements

## File Structure

- `data/`: Original air quality CSV files
- `functions.R`: R function for cleaning daily air quality data
- `data_exploration.R`: Data processing, summary tables, and plots
- `Project2.Rmd`: R Markdown report
- `Project2.docx`: Final Word report

## How to Reproduce

1. Open `BIOSTAT721_Project2.Rproj` in RStudio.
2. Install the required R packages if needed: `tidyverse`, `lubridate`, `rmarkdown`, and `knitr`.
3. Open `Project2.Rmd`.
4. Click **Knit to Word** to generate the report.
